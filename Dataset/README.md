# Dataset

The complete dataset is hosted publicly on [Kaggle](https://www.kaggle.com/datasets/arvindmukundan/counterfeit-hologram-and-currency-samples).

```bash
kaggle datasets download -d arvindmukundan/counterfeit-hologram-and-currency-samples --unzip
```

The original dataset folder structure and source checksum manifest are included in the Kaggle download.
